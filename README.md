
# lb-ite4
gitの練習用です。

## 手順
1. 1人のユーザーが**リモートリポジトリ**を作成
2. リモートリポジトリを**クローン**し、**ローカルリポジトリ**を作成
3. 新規**ブランチ**（仮にsampleブランチとする）を作成
4. コーディング作業終了後、 **コミット**
5. sampleブランチをリモートリポジトリに**プッシュ**\
   *※差分がある場合プッシュできないので、フェッチ + マージ後にプッシュ*
6. **プルリクエスト**を作成 ← 今回やってない（現場の指示に合わせて）
7. 新しい作業をする前に最新のソースをリモートリポジトリから**フェッチ**する
8. 差分があれば、ローカルリポジトリに**マージ**する

## 前提条件
プッシュするユーザーは事前にgithubの該当プロジェクトに権限を追加すること
